# TAPD for Orca

TAPD for Orca connects TAPD work items to Git workspaces in Orca.

## Language

**TAPD project**  
The TAPD project that contains a requirement, task, or defect.

**Current Orca Git project**  
The Git project that owns the focused Orca workspace in the current window.

**Destination Orca Git project**  
The Git project and host where an Orca workspace is created for a TAPD work item.
