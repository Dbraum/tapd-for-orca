# TAPD for Orca

TAPD for Orca is a development sidebar for browsing TAPD work and starting development in Orca Git workspaces.

## Language

**TAPD project**  
The TAPD project that contains a requirement, task, defect, or board item.

**TAPD requirement (Story)**

A work item that describes a user need or a deliverable outcome. A requirement can have related tasks and can also belong to a parent requirement.

**TAPD task (Task)**

A work item for a piece of execution work. It can belong to one TAPD requirement or stand on its own.

**Development task**

A TAPD task that defines one independently verifiable development deliverable and serves as the entry point for that work in Orca.

**TAPD board item (ITEM)**

A work item on a TAPD board. It can contain checklist items that track steps within the card.

**Current Orca Git project**  
The Git project that owns the focused Orca workspace in the current window.

**Destination Orca Git project**  
The Git project and host where an Orca workspace is created for a TAPD work item.
