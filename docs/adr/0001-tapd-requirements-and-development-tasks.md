# TAPD 需求承载规格，任务承载开发交付

研发协作的 TAPD Story 是规格和整体验收的记录，TAPD Task 是独立开发交付的记录，并保留与所属需求的原生关联。Orca 从任务启动开发，Git PR 回链对应任务，让需求、开发进度和交付证据可以沿同一条关联追溯。

已有需求沿用原记录。目标、范围和整体验收条件确认后更新或创建需求，任务草稿和阻塞关系经确认后再逐张创建。范围局部且可独立验收的改动可以直接创建独立任务。

可开工的任务写明交付行为、验收标准和阻塞任务。每张任务交付可以独立演示或验证的行为，实际阻塞解除后才开始开发。

Agent 开工时接收任务的交付行为和验收标准，以及所属需求的目标、范围和链接。需求变更影响当前任务验收时，由负责人先确认并更新任务。PR 合并、任务验收通过并回填验证结果后，任务可以结束。关联任务全部完成后，由需求负责人确认整体验收。
