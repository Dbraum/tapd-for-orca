# Changelog

## 0.2.0

- Browse your TAPD to-dos across projects, including requirements, bugs, tasks, and board cards.
- Filter by project or type, sort by due date or last update, and see when some projects could not load.
- Open to-do details and start or reopen linked Orca workspaces from the sidebar.

## 0.1.1

- Preselect the current Git project when starting an Orca workspace from a TAPD work item.
- Use the destination host’s default Agent on Orca builds that support it.

## 0.1.0 (unreleased)

- Browse and search TAPD requirements, bugs, and tasks from the Orca sidebar.
- Create, edit, change status, and comment as allowed by your TAPD project.
- Create a workspace from a work item, optionally launch an agent with context, and reopen the linked workspace later.
